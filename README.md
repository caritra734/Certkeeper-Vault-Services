These pages are directly created and hosted in Salesforce dev sandbox and so I have not further re-hosted them in Netlify.

1. Color Pattern and Rationale
The palette uses a professional base of [ Navy or Dark Gray] for trust, paired with a high-contrast [Green or Blue] for action buttons. This combination ensures a clean, modern aesthetic while visually guiding users toward the primary conversion goals.

2. Web Page Descriptions and UX
The Landing Page uses a minimalist layout to focus user attention on a single offer and a streamlined Pardot lead-generation form. The Thank You Page provides immediate confirmation of the submission and offers clear next steps to maintain user engagement.

3. Frameworks, Tools, and Applications
Pardot served as the hosting and automation engine, while HTML5/CSS3 provided the custom structure and responsive styling for the templates. GitHub was utilized for version control and code documentation, ensuring a secure and organized backup of the site's source files.
